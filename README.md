# 卡卡西 · 个人博客

一个记录前端项目、技术思考和日常灵感的静态个人主页。

## 页面内容

- 个人介绍与成都城市信息
- AI 智能分析、AI 粮仓数字人、小程序与 CRM 项目经历
- Python、Vue、React、MySQL 技术栈
- 可筛选和搜索的文章卡片、文章阅读弹窗
- 唱歌、旅行、美食等生活兴趣
- 邮箱与 GitHub 联系入口

## 本地预览

直接在浏览器打开 `index.html`。头像 `white_background_portrait.jpg` 需要与页面文件放在同一目录。

## Netlify

项目是纯静态页面，发布目录为仓库根目录。仓库已附带 `netlify.toml`，连接 Git 仓库后可直接发布。
